HOLD MY ITEMS - Minecraft 26.3 (unofficial port)

OPTION A - On your PC
  1. Install JDK 25 (https://adoptium.net, pick Temurin 25).
  2. Windows: double-click build.bat      Mac/Linux: run ./build.sh
  3. First run downloads Gradle, Loom and Minecraft (needs internet, takes a few minutes).
  4. Jar appears in build/libs/ -> use holdmyitems-5.1.3+26.3.jar (NOT the -sources jar).

OPTION B - On GitHub
  1. Create a repo and upload EVERYTHING in this folder (including the hidden .github folder).
  2. Open the Actions tab -> Build run -> download the "holdmyitems-26.3" artifact.

INSTALL: put the jar in .minecraft/mods with Minecraft 26.3, Fabric Loader 0.19.5+,
Fabric API (26.3) and Java 25.

If the build fails, copy the error text from the console / Actions log and send it back.
